# ID Tool

This is an ID number generation and validation tool designed for learning, demonstration, and testing purposes. It includes:

- Interactive menu mode
- Command-line mode
- 17-digit checksum calculation
- 14-digit basic information enumeration
- Controlled batch generation (limited / unlimited)

## Important Notice

- This project is for learning, testing, demonstration, and simulation purposes only.
- Strictly prohibited for any illegal use, identity fraud, privacy violations, or activities that violate local laws and regulations.
- Do not submit real personal information, real identity card numbers, or real area code data to this repository.
